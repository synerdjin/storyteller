# Sourcebooks

Drop rulebooks, setting guides, bestiaries, or any lore you want the Game Master to use into this folder — PDFs, markdown, plain text, whatever you have.

**You don't have to convert anything.** When the GM first needs a book during play, it reads the relevant parts and saves a compact summary into `_digests/`. From then on it consults that lightweight digest instead of re-reading the whole file every time — faster, and it keeps the GM focused on your story.

If you add a full **rules system** here, it **overrides** the simple built-in dice mechanic. Just tell the GM "use this system" and it'll play by those rules.

`_digests/` is created and maintained by the GM. You're welcome to read the digests, but you don't need to touch them.
