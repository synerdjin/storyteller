# Current scene

> A live snapshot of "right now," overwritten as the scene changes so the game can resume instantly. On a returning session the GM reads this first.

## Where & when
*The campaign clock — the GM's single source of truth for "now." Lead with the day count so elapsed time stays computable, e.g.* `**Day 14 — 3rd of Frostmoon, evening.** The Salt Quarter, after the storm.` *Day 1 = the first scene; advance the count whenever in-fiction time passes.*
