# Control ledgers — who holds the contested things (GM ONLY)

> GM-only, and **tool-owned**: `Tools/ledger.py` (via `world_tick.py`) writes
> this file. Each contested entity is a pool of control points that shift by
> fixed, deterministic rules as rivals press on it — never set by a model.
> The number is the fairness; the prose only interprets it. Never quote to
> the Player or hand to an `npc-actor`.

*(no contested ledgers yet — they open when a collision over a shared target is first detected.)*
